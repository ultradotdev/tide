# Tide v0.13.2 Release Notes

Tide 0.13.2 works with TypeScript 7, says plainly when a project has no TypeScript, and shows each Status History message in full.

## Changes

- **TypeScript 7.** TypeScript 7 has its own language server and no `tsserver.js`, so TypeScript files in a TypeScript 7 project got no completions, hovers or diagnostics. Tide now starts TypeScript 7's `tsc --lsp --stdio` for those projects, and keeps using `typescript-language-server` for TypeScript 5. It uses the TypeScript nearest the file: the project's own `node_modules` first, then the global install. See [the editor guide](features/editor.md).
- **Larger Status History.** Status History is larger, and selecting a message shows it in full instead of cut off at the edge.

## Fixes

- **No TypeScript, said plainly.** When a workspace had no TypeScript, the status showed a raw language server error. It now says that no TypeScript was found and how to install it. A language server that cannot start, or stops unexpectedly, now says which of the two happened while Tide waits to retry.

## Upgrading

- Homebrew: `brew update && brew upgrade tide`
- Install script: re-run it, or run Help: Check for Updates for the command.

Settings, key bindings, sessions and history from 0.13.1 carry over.

See [getting started](getting-started.md), [configuration](reference/configuration.md), [troubleshooting](troubleshooting.md) and [security](../SECURITY.md).
