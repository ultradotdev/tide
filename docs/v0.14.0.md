# Tide v0.14.0 Release Notes

Tide 0.14.0 adds two new Ultra themes and makes Ultra Vivid the default. It also replaces the Welcome card with a start page, and shows these notes the first time you start a new version.

## Changes

- **Ultra Vivid and Ultra Broadcast.** Two new themes, both built from the Ultra design tokens. Ultra Vivid is now the default theme. If you haven't chosen a theme, Tide switches to Vivid. To keep the old look, set `workbench.colorTheme` to `ultra-dusk`. See [themes](features/themes.md).
- **Start page.** The Welcome tab is now a start page:
  - actions to open a file, create a file, open a terminal, start an agent, open Source Control and open the command palette, each showing its current key
  - your recent files and saved sessions
  - links to the guides

  Use the arrow keys and Enter, or click.
- **Release notes after an upgrade.** The first time you start a new version of Tide, it opens these notes in a tab. You can open them at any time with Help: Release Notes. To stop them opening on their own, set `update.showReleaseNotes` to `false`.

## Upgrading

- Homebrew: `brew update && brew upgrade tide`
- Install script: re-run it, or run Help: Check for Updates for the command.

Settings, key bindings, sessions and history from 0.13.2 carry over. If you haven't chosen a theme, Tide now uses Ultra Vivid; see above to keep Ultra Dusk.

See [getting started](getting-started.md), [configuration](reference/configuration.md), [troubleshooting](troubleshooting.md) and [security](../SECURITY.md).
