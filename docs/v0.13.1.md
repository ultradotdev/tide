# Tide v0.13.1 Release Notes

Tide 0.13.1 shows Markdown files formatted, lets you split a pane from its tab list, says when it is quitting, and stops mouse movements turning up in your shell after you quit.

## Changes

- **Markdown preview.** Markdown files (`.md` and `.markdown`) open formatted: headings, bold and italic, code, links, lists, quotes and tables, laid out for the pane's width. The status bar shows **Preview**; click it, or run **Toggle Markdown Preview**, to see the source in the same tab and edit it, and it shows **Edit**. Each tab keeps its own view, and the session remembers it. In the preview, the arrow keys, Page Up, Page Down, Space, Home, End and the mouse wheel scroll, and typing does nothing; commands that work on the text, such as find, undo or paste, switch to the source first, and saving saves the source. `editor.markdown.openMode` chooses how Markdown files open: `preview` or `edit`. See [the editor guide](features/editor.md).
- **Split from the tab list.** The `▾` list of a pane's tabs ends with **Split Right** and **Split Down**, which split that pane without taking room in its tab bar.
- **Quitting says so.** Closing waits up to 2 seconds for language servers and database sessions. If it takes more than half a second, a box in the middle of the screen says "Quitting Tide…", so it no longer looks like a hang.

## Fixes

- **No mouse movements in the shell after quitting.** Tide kept mouse tracking on while it shut down, and switched the terminal back before turning it off, so moving the mouse while Tide closed left text such as `^[[<35;84;28M` at the shell prompt. Tide now turns mouse and focus reports off as soon as you quit, and throws away any it did not read before handing the terminal back.

## Upgrading

- Homebrew: `brew update && brew upgrade tide`
- Install script: re-run it, or run Help: Check for Updates for the command.

Settings, key bindings, sessions and history from 0.13.0 carry over.
