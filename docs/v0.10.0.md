# Tide v0.10.0 Release Notes

Tide's active implementation is now native Rust. This candidate is not a published release.

## Changes

- Native executable with embedded catalogs, themes and grammars, plus native PTY/emulator integration.
- Restored pane menus, sidebar controls, provider accordions, clickable tabs/dialogs, overflow navigation, file-type icons and proportional scrollbars.
- Wrapped modal text, action-specific button styling and outside-click dismissal with unsaved-change guards.
- Find/replace options and PostgreSQL schema, sortable results and eligible row mutation workflows.
- Shared source/local/release installation, verified payloads, retained rollback and ownership-aware uninstall/purge.
- Four target artifacts, Ubuntu 22.04 / glibc 2.35 Linux floor, Developer ID hardened macOS packaging and API-key notarization workflow.
- Compiled runtime reference generation and Rust-focused documentation.

## Compatibility

Use release-profile builds for interactive testing. The executable has no Bun or PTY-sidecar runtime dependency. Supported external coding-agent CLIs remain separately installed and authenticated.

Rust keeps its session snapshots separate from historical TypeScript writes. Back up configuration, data and state before switching.

Database results currently share their SQL editor tab rather than a separate result tab. Public downloads, WSL support and automatic updates are unavailable. Signing, artifact validation and human acceptance must finish before release promotion.
