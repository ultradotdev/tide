# Tide v0.14.1 Release Notes

Tide 0.14.1 lets you open the start page at any time, and gives its tab a clearer name.

## Changes

- **View: Start Page.** The start page used to appear only when Tide started, so once you closed it there was no way back. Run View: Start Page from the command palette to open it in the current pane, or to switch to it if it's already open. It has no default key; bind `workbench.startPage` to give it one.
- **Start Page tab.** The start page's tab was called Welcome, the same name as the Welcome guide. It's now called Start Page. Help: Welcome still opens the guide.

## Upgrading

- Homebrew: `brew update && brew upgrade tide`
- Install script: re-run it, or run Help: Check for Updates for the command.

Settings, key bindings, sessions and history from 0.14.0 carry over.

See [getting started](getting-started.md), [configuration](reference/configuration.md), [troubleshooting](troubleshooting.md) and [security](../SECURITY.md).
