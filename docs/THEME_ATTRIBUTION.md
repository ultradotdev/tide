# Built-in Theme Attribution

Tide maps open-source color palettes into its own semantic terminal UI roles.
The mappings are adaptations; the upstream projects do not endorse Tide.
Exact source revisions are recorded in
[`config/theme-provenance.json`](../config/theme-provenance.json).
