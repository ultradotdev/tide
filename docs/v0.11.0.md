# Tide v0.11.0 Release Notes

Tide 0.11.0 makes the command palette cover all of Tide, adds 56 commands, and opens a Welcome guide the first time Tide starts.

## Highlights

- **Every command is in the palette.** Press `Ctrl+K`, `Ctrl+Shift+P` or `F1` and type. Commands that used to be reachable only as keys inside a panel are listed too: Explorer rename and delete, Source Control stage and discard, query result actions and the focus commands.
- **Welcome and Help.** The first time Tide starts without a file, it opens a Welcome guide. Fourteen Help pages cover getting started, the editor, Git, terminals, PostgreSQL, agents, themes, keys, commands and settings; open any of them with a `Help:` command. They show your own key bindings, settings and install method, so they stay accurate after you change them. `workbench.startupEditor` controls the first-run page.
- **Help: Check for Updates** asks GitHub for the latest release when you run it, and shows the update step for how you installed Tide. Tide never checks on its own.

## New commands

- **Editor:**
  - move lines up or down (`Ctrl+Shift+Up`/`Down`), delete line, indent and outdent, join lines
  - upper, lower and title case; sort lines; trim trailing whitespace
  - toggle block comment, format selection, fold levels 1–3
  - toggle the minimap, toggle zen mode
- **Files:** rename, delete, new folder, copy path and relative path, Reveal in Finder (or your file manager), close other tabs.
- **Language servers:** go to declaration, type definition and implementation, with a picker when there are several results; restart the language server.
- **Terminals:** clear the screen and scrollback, kill the running program, scroll to top or bottom, close all terminals.
- **Git:**
  - stage or unstage the active file
  - discard changes in a file or in all files, clean untracked files
  - amend the last commit, pull with rebase, fetch all remotes, force push with lease
  - rebase onto a branch; continue or abort a stopped rebase, cherry-pick, revert or merge; open conflicted files
  - create a tag, cherry-pick a commit, revert a commit, reset to a commit
  - Destructive Git commands ask first and name what they will change.
- **Search:** Replace in Files, with a preview of every file and match count before anything changes. Open files change in their editors, so you can undo there.
- **Sessions:** list and delete this workspace's saved sessions.

## Fixes

- `--no-session` no longer overwrites the folder's saved session when you quit.
- Space in Source Control folds the selected group instead of collapsing the whole panel.
- While the sidebar or another region has focus, a terminal tab no longer takes shell keys such as `Ctrl+K`.
- Key hints show your own bindings, and the SQL tab no longer suggests `F5`, which was never bound.
- Comment Line and Uncomment Line each do one thing, and Duplicate Selection duplicates the selection.
- Choosing a result in Find All References or Go to Symbol in Workspace opens the file.
- Sidebar commands find their panel even after you remove or reorder panels.
- `uninstall.sh` run from a source checkout hands off to the installed release's uninstaller.

## Changes

- Some command IDs that duplicated another command are now aliases. They keep working in your key bindings: `view.toggleSidebar`, `view.toggleTerminal`, `workbench.saveSession`, `quit`, `git.status`, `git.branches`, `git.checkout`, `git.openFileDiff`, `git.viewChanges`, `git.viewStagedChanges`, `gitPanel.stageAll`, `gitPanel.commit`, `gitPanel.refresh` and `queryResults.export`.
- Stage Changes and Unstage Changes now act on the active file. The Source Control panel's own Stage and Unstage commands still act on its selection.
- Commands and settings that nothing implemented were removed from the catalogs.

## Upgrading

- Homebrew: `brew upgrade tide`
- Install script: re-run it, or run Help: Check for Updates for the command.

Settings, key bindings, sessions and history from 0.10.0 carry over. A setting or key binding that names one of the removed commands or settings has no effect.

See [getting started](getting-started.md), [configuration](reference/configuration.md) and [security](../SECURITY.md).
