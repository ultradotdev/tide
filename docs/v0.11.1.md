# Tide v0.11.1 Release Notes

Tide 0.11.1 tells you when a new release is out, fixes the Homebrew update instructions and removes the close button from sidebar sections.

## New

- **Automatic update check.** At most once a day, when Tide starts, it makes the same single HTTPS request as Help: Check for Updates. If a newer release is out, the status bar says so; run Help: Check for Updates for the update step. Nothing is shown when Tide is up to date or GitHub can't be reached. Set `update.checkAutomatically` to `false` to turn it off, or set `TIDE_NO_UPDATE_CHECK=1` in the environment.

## Fixes

- **Homebrew updates:** Homebrew refreshes its taps only once a day before `brew upgrade`, so `brew upgrade tide` alone could report an older Tide as current for up to a day after a release. Help: Check for Updates, the README, Getting Started and Welcome now say `brew update && brew upgrade tide`.
- **Sidebar sections:** section headers no longer have a `×`. Clicking a header folds or unfolds its section. If a saved session is missing a section, add it back with `Ctrl+Shift+A` or a **Sidebar: Add** command, such as **Sidebar: Add Source Control**.

## Upgrading

- Homebrew: `brew update && brew upgrade tide`
- Install script: re-run it, or run Help: Check for Updates for the command.

Settings, key bindings, sessions and history from 0.11.0 carry over.

See [getting started](getting-started.md), [configuration](reference/configuration.md) and [security](../SECURITY.md).
