# Tide Website Content Guide

## Approved language

**Headline:** Terminal-Native Agentic IDE

**Description:** Code, Git, databases, terminal, editing, agent CLIs and more, all in one terminal-native workspace.

Use **Tide** as the product name and **Tide by Ultra.dev** as the endorsement. Label version 0.10.0 as the first public release.

## Permitted claims

The site may claim only features listed in `features.releaseReady` in `tide-release.json`. It may describe the five external AI CLI integrations listed there.

## Prohibited claims

- Do not add features that are absent from the release-ready inventory.
- Do not claim WSL support.

## Authoritative fields

Treat product identity, release status, platform support, artifact filenames, commands, paths, feature inventories, provider support, and URLs in `tide-release.json` as authoritative. An artifact's download button is enabled only when both its status and the distribution status are published.
