# Tide v0.12.2 Release Notes

Tide 0.12.2 fixes Codex sessions that failed to load or start on busy machines, keeps the Agents sidebar's keys and errors readable, and stops a startup warning for settings saved by Tide 0.10.0.

## Fixes

- **Codex sessions load with long histories.** The Agents sidebar lists your Codex sessions through `codex app-server`, which returns 100 of them at a time. Tide gave it 5 seconds in total, so with a few hundred sessions, or while Tide itself was starting, the list timed out and the sidebar showed "Codex native catalog: Codex app-server timed out". It now has 15 seconds. New Codex sessions, renames and archives get the same time, so a slow Codex start no longer stops a new session from opening.
- **The Agents sidebar footer wraps.** Its keys used to be cut off at the default width, ending in "w w" instead of "w workspace", and an error kept only its first words, such as "Codex native catalog:", hiding the reason. The footer now uses up to three rows, wraps between keys, and ends a message that is still too long with "…".
- **No warning for settings Tide 0.10.0 saved.** Tide 0.10.0 wrote every default into `settings.jsonc` when you changed any setting, including `"workbench.startupEditor": ""`. Later versions showed a Configuration Problems dialog for it at every start. Tide now reads that value as the default and says nothing. You can also delete the line.
- **Safer OpenCode session actions.** Tide sends only Delete to OpenCode's session API, and refuses any other action before starting OpenCode.

## Upgrading

- Homebrew: `brew update && brew upgrade tide`
- Install script: re-run it, or run Help: Check for Updates for the command.

Settings, key bindings, sessions and history from 0.12.1 carry over.
