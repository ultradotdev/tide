# Tide v0.12.1 Release Notes

Tide 0.12.1 colours the Explorer's file icons, fixes folder icons that were cut off, and makes the Settings list easier to use.

## New

- **Coloured Explorer icons.** With Nerd Font icons on, each file type has its own icon and colour. For example, Rust and HTML are orange, TypeScript, Python and CSS are blue, JavaScript and folders are yellow, and JSON and shell scripts are green. About 60 file types are covered, up from 13, plus special names such as `Dockerfile`, `Makefile`, `Cargo.toml`, `package.json`, `LICENSE`, `.env` and `.gitignore`. The colours come from the theme's terminal colours, so they follow the theme you choose and stay readable on light themes. A file's name keeps its Git status colour.
- **Settings you can pick instead of type.** In the Settings list:
  - **Settings with fixed values**, such as `tui.iconStyle`, `tui.colorMode` and `editor.wordWrap`: Enter opens a list of the allowed values, with the current one marked and the default labelled. Esc goes back.
  - **On/off settings:** Enter flips the value.
  - **`workbench.colorTheme`:** Enter opens the theme list.
  - **Number settings:** the prompt shows the allowed range.
  - **The list** shows each value without JSON quotes and the selected setting's description underneath.
  - **A wrong value** is now explained, for example "editor.tabSize must be a whole number from 1 to 16" instead of "Invalid value".

## Fixes

- **Folder icons are no longer cut off.** With a non-Mono Nerd Font, such as SauceCodePro Nerd Font, the folder and symlink icons were drawn too wide for their space and some terminals cut off their right edge. They now use narrower glyphs that fit like the file icons.
- **The theme list starts on your current theme.**

## Upgrading

- Homebrew: `brew update && brew upgrade tide`
- Install script: re-run it, or run Help: Check for Updates for the command.

Settings, key bindings, sessions and history from 0.12.0 carry over.
