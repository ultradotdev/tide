# Tide v0.12.0 Release Notes

Tide 0.12.0 lets you copy from terminals, formats the help pages, adds shortcuts and everyday names to the command palette, and reloads settings when you edit them by hand. It also fixes a set of problems that could lose work or block common workflows.

## New

- **Copy from terminals.** Drag to select in the bottom dock, terminal tabs and agent tabs; double-click selects a word and triple-click a line. Selections can reach into the scrollback. With `terminal.copyOnSelect` (default `true`) the selection is copied when you let go. **Copy Terminal Selection** is in the palette, and `Ctrl+Shift+C` or `Cmd+C` copy where the terminal passes them on. When a program such as vim or htop uses the mouse, hold Shift to select.
- **Copy over SSH and tmux.** `clipboard.osc52` (default `auto`) sends copies to your local terminal with OSC 52 in an SSH session, or whenever the system clipboard helper fails. Inside tmux it works with `set-clipboard on` or `allow-passthrough on`.
- **Formatted help.** Help pages show styled headings, aligned tables, wrapped lists and coloured inline code instead of raw Markdown. They lay out again when the pane is resized, and Find, selection and copy still work.
- **Palette shortcuts and keywords.** Each command shows the key that runs it from where you opened the palette. Everyday names find commands: `new terminal`, `settings`, `preferences`, `keyboard shortcuts`, `git push`, `dark mode`, `grep`, `exit` and more. The last 8 commands you ran are listed first.
- **Live settings reload.** Hand edits to `settings.jsonc` and `keybindings.jsonc` apply within 2 seconds, or as soon as the window regains focus. If a file stops parsing, **Configuration Problems** names the file, line and column, and Tide keeps the last good configuration.
- **Indentation and `.editorconfig`.** Tide detects tabs or spaces and the indent width from each file, and reads `.editorconfig` (`indent_style`, `indent_size`, `tab_width`, `end_of_line` for new files, `insert_final_newline`, `trim_trailing_whitespace`). The status bar shows what's in effect. Turn detection off with `editor.detectIndentation`.
- **Commit message bodies.** The commit box is multi-line: Enter starts a new line and `Ctrl+S` commits. The draft is kept if you close the box or the commit fails, and Commit (Amend) shows the whole message.
- **Rebases and detached HEAD in Source Control.** Source Control shows `HEAD detached at …`, and a paused rebase, merge, cherry-pick, revert, bisect or `git am` shows its progress, for example "Rebasing main onto 1a2b3c4d (3/7)".
- **PostgreSQL TLS modes work like libpq.** `prefer` and `require` encrypt without checking the certificate, and `verify-ca` and `verify-full` check it. Unset modes on remote hosts, and connections saved by earlier versions, are still fully checked. Certificate errors now give the cause and a way forward.
- **Project database passwords.** Type a password in the connection form and Tide keeps it in your secret store, tied to that exact destination; the shared `.tide/connections.json` never holds it. `~/.pgpass` and `PGPASSFILE` are read as libpq reads them.
- **Colour for every terminal.** `tui.colorMode` (default `auto`) sends 24-bit colour where the terminal supports it and maps to the 256-colour palette elsewhere, such as Terminal.app before macOS 26.
- **Keys that work everywhere.** `F12` Go to Definition, `Shift+F12` Find All References, `F2` Rename Symbol, `Ctrl+F2` Select All Occurrences and `Ctrl+_` Toggle Comment work in terminals without the kitty keyboard protocol. Word motion (`Ctrl+Left/Right`, `Alt+Left/Right`, `Alt+B/F`), word deletion, `Ctrl+Home/End` and smart Home are new in the editor.

## Fixes

- **Terminals get their keys.** A focused terminal receives every `Ctrl+letter`, so nano, emacs, the tmux prefix, readline and agent CLIs work inside Tide. `F1` opens the palette from a terminal.
- **Quitting asks first** when a terminal or agent is still running a program, instead of stopping it.
- **Edits survive a hangup.** Closing the window, a dropped SSH connection, `SIGHUP` or `SIGTERM` now saves the recovery snapshot at once. Start Tide in the same folder to get the edits back.
- **Read-only files** show `[RO]` and ask before Save overwrites them.
- **Files changed outside Tide reload** when the tab has no unsaved edits, as one undo step. A tab with unsaved edits is reported once.
- **Git no longer gives up after 15 seconds.** Push, pull, fetch, commits with hooks or signing, and other remote commands get 10 minutes. SSH passphrase and host-key prompts no longer hang behind Tide's screen, and errors say what to do next.
- **Settings files keep their comments.** Changing a setting or key binding edits just that value. A file that doesn't parse is never overwritten.
- **Quick Open and Find in Files** skip `.git` and `files.exclude` (`node_modules` by default) and rank file-name matches first.
- **Shortcuts in kitty, Ghostty and WezTerm.** Tide now turns on the kitty keyboard protocol after switching to the alternate screen, where the terminal applies it.
- **Go to Line** replaces the pre-filled number as you type, and every prompt that opens with a value starts with it selected.
- **The Git gutter** marks only the lines that changed, not the surrounding context.
- **The Keyboard Shortcuts editor** changes the row you picked, not the first command that shares its key.
- **Agents sidebar:** no more false errors when OpenCode or Gemini has no sessions, and a CLI that isn't signed in says so calmly.

## Security

- `tar` 0.4.46 fixes a PAX header desync ([GHSA-3cv2-h65g-fgmm](https://github.com/advisories/GHSA-3cv2-h65g-fgmm)).
- The encrypted secret store moves to aes-gcm 0.11 and scrypt 0.12. Stores written by earlier versions still open, and a store with a malformed IV is rejected instead of crashing Tide.

## Upgrading

- Homebrew: `brew update && brew upgrade tide`
- Install script: re-run it, or run Help: Check for Updates for the command.

Settings, key bindings, sessions and history from 0.11 carry over. Some defaults changed:

- In a focused terminal, `Ctrl+letter` keys now go to the shell. Use `F1` for the palette, and `Ctrl+Alt+arrows` or `F7`/`F8` to move between panes.
- `tui.iconStyle` defaults to `auto`: Nerd Font icons in Ghostty, kitty and WezTerm, and plain text elsewhere. Set it to `nerd` if your terminal font is a Nerd Font.
