# Commands

Every command is in the command palette ({{key:workbench.commandPalette}}): type part of its name and press Enter. Commands for the Explorer, Source Control, Outline and Timeline panels and for query results act on that panel's selection, revealing the panel first. Keys are listed where a command has one, using your current bindings. The ID is what you use in {{path:keybindings}}.
